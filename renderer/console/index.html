      Sound
      Music and both games play through the laptop’s main output. To use another output (the PA), pick it in Windows’ sound settings: the launcher follows.
      Stream Deck 15 keys
      Main page
      The Music folder (key 15)
      1. Install Elgato’s Stream Deck app and plug the Stream Deck in.
      2. On each key of the main page, drop a Hotkey action (System). Click the arrow beside its Hotkey box and pick the key shown on the tile (F13 to F23 are in the list; for Shift or Ctrl keys pick that too). Title it with the tile’s words.
      3. On key 15, drop a Create Folder action and name it Music. Open it and set its keys the same way (its top-left key is the folder’s own Back).
      4. Turn on Test the buttons and press every key: its tile lights here and nothing happens in the show.
      The keys work whichever window has the focus. Clicking a tile here does what its key does.
